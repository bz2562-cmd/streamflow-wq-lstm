# streamflow-wq-lstm

Exploratory analysis of the Caravan-Qual water quality dataset and model architecture inspection of the encoder-decoder LSTM from Nearing et al. (2024), as part of a research plan for machine learning based streamflow and water quality prediction.

## Contents

- `main.py` : data exploration and figure generation (6 figures)
- `nh_explore.py` : NeuralHydrology model architecture inspection
- `plots/` : all generated figures
- `report.md` : semester report

## Data

Caravan-Qual lite : https://zenodo.org/records/17787066
